# Memory map

Use existing files and templates; extend only where a real need emerges. Never replace a populated foundation with a blank template.

| Information | Canonical destination |
| --- | --- |
| Current situation and headline direction | `profile/positioning.md` |
| Practical needs, preferences, trade-offs | `profile/preferences.md` |
| Aspirations and open possibilities | `profile/ambitions.md` |
| Effective working conditions and examples | `profile/working-style.md` |
| Culture requirements and warning signs | `profile/culture-fit.md` |
| Tone and language preferences | `profile/writing-voice.md` |
| Role or other experience | `experience/<descriptive-slug>.md`, using `templates/experience.md` |
| Substantial reusable story | `case-studies/<descriptive-slug>.md`, using `templates/case-study.md` |
| Concise proof points linked to sources | `evidence/evidence-bank.md` |
| Capability, depth, recency, limitations | `skills/capabilities.md` |
| Career-related interpretations awaiting validation | `onboarding/hypotheses.md` |
| Coverage, unfinished threads, resume point | `onboarding/progress.md` |
| Meaningful stable changes and corrections | `changelog/memory-updates.md` |

Maintain links in `experience/README.md` and `case-studies/README.md` as records grow. Index evidence, do not duplicate whole stories. If a fact is corrected, update its canonical record and affected summaries; note the correction without treating outdated content as current.

Record source and date for meaningful claims, plus whether user-reported, supplied-document, independently verified, or uncertain. A confirmed preference is not a scientific personality finding. Preserve nuances and conditions alongside preferences.

Create only records supported by actual content. Unknown stays unknown; unasked, skipped, and declined-to-record are distinct. For a do-not-save request, keep at most a neutral instruction to avoid that topic if the person permits, not the underlying detail. Do not leave prohibited content in a changelog. Explain Git history implications if asked to remove content that was already committed.
