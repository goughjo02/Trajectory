# Opportunities

Keep each role and its history in `<organisation>-<role>-<yyyy-mm>/`. Search existing workspaces first; different recruiter names can refer to the same role. Copy `_template/` when a new workspace is needed.

Bring back recruiter replies, interview notes, decisions, changed deadlines, and your reactions. This keeps advice and follow-ups grounded in the latest position. Raw sensitive material may go in the optional ignored `private/` folder; record useful, appropriate summaries in the interaction log.

The brief holds current status and next action. Logs distinguish event dates from when information was recorded. No inbox monitoring or reminders run automatically.
